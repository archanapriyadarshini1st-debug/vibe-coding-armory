# Agent Browser Skill

Browser automation capability for agents that need to inspect, interact with, and validate web applications through a real browser workflow.

## Best for
- opening and navigating sites
- clicking, typing, scrolling, and extracting visible state
- validating UI behavior end-to-end
- reproducing browser-specific issues
- automated website QA

## Reference
Use an established Agent Browser implementation; keep the exact runtime/tooling dependency separate from this Armory catalog.

Suggested starting point: https://github.com/vercel-labs/agent-skills
