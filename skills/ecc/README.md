# Everything Claude Code (ECC)

Saved reference for the **Everything Claude Code (ECC)** skill system by affaan-m.

## Source
- Repository: https://github.com/affaan-m/everything-claude-code

## What this provides
ECC is a collection of reusable skills, agents, commands, hooks, rules, and workflows for AI coding agents. It includes workflows such as:
- search-first
- TDD workflow
- verification loop
- agentic engineering
- skill scouting
- security review
- continuous learning / memory

## Usage
Treat ECC as a reusable skill library for this armory. When a coding task would benefit from one of these workflows, inspect the upstream ECC implementation and adapt the relevant skill rather than reinventing the workflow.
