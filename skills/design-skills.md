# New Design Skills

Three high-value design/engineering skill repositories added to the Vibe Coding Armory.

## Impeccable — pbakaus
- Repository: https://github.com/pbakaus/impeccable
- Purpose: Frontend design guidance for AI coding agents, covering production UI, UX, typography, layout, motion, accessibility, responsive behavior, performance and refinement.
- Current reference: Impeccable documents a skill plus 23 commands and deterministic design detectors.
- License: Apache-2.0

## Taste Skill — Leonxlnx
- Repository: https://github.com/Leonxlnx/taste-skill
- Purpose: Anti-slop frontend framework for AI agents, focused on stronger layout, typography, motion, spacing and coherent design systems.
- Current default skill: `design-taste-frontend` (v2 experimental).
- License: MIT

## Skills — Emil Kowalski
- Repository: https://github.com/emilkowalski/skills
- Purpose: Design-engineering skills focused on interaction and animation quality, including the small implementation decisions that make interfaces feel polished.

## How they fit the Armory
1. Impeccable — audit and improve production UI quality.
2. Taste Skill — prevent generic/templated frontend output.
3. Emil Kowalski Skills — refine interaction and motion craft.

Use these as guidance layers alongside the component, animation, 3D and asset libraries already catalogued in this repository.
