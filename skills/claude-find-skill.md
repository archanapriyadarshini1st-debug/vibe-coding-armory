# Claude Find Skill

## Purpose
A discovery skill for Claude Code that helps locate relevant skills the user does not already have.

## What it does
- Interprets requests such as "is there a skill for X?"
- Searches skill sources and ranks relevant candidates.
- Avoids recommending skills that are already installed/covered.
- Verifies that a candidate actually follows the Agent Skills format before recommending it.

## Source
https://github.com/oleksbard/claude-find-skill

## Note
This is a third-party Claude Code skill. Treat it as a discovery/reference tool rather than a replacement for the official Vercel `find-skills` skill.
