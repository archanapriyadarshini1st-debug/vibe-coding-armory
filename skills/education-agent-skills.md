# Education Agent Skills Library

A broad education-focused agent-skill library for evidence-based teaching, curriculum design, assessment, learning science, AI literacy, inclusive design, and student-facing learning workflows.

## Focus
- lesson and curriculum design
- memory, learning science, and metacognition
- assessment and rubric design
- questioning, dialogue, and literacy
- AI learning science and AI literacy
- inclusive and alternative pedagogies
- student-facing study-session skills
- composable agent orchestration through the Agent Skills format

## Upstream Reference
https://github.com/GarethManning/education-agent-skills

Prefer the upstream implementation when installing/running the skill. The upstream library currently describes 165 skills across 20 education domains and includes Codex/Agent Skills-compatible installation paths.
