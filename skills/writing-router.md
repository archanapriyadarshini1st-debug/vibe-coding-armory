# Writing Router

Routing skill for choosing the smallest appropriate writing skill set instead of applying every writing rule to every task.

## Route
- Story, character, scene, dialogue → creative writing / writing craft
- Essay, research, analysis → academic writing
- School question or marks-based response → school answer writing
- Letter, notice, report, speech, debate → school format writing
- Email, proposal, brief, client/workplace text → professional writing
- General rewrite/edit → general writing
- Final cleanup → proofreading + human-quality editing
- Mixed tasks → compose with the domain skill first, then run general writing as a final pass

## Priority
1. User instructions and required format
2. Source/textbook/rubric constraints
3. Domain-specific writing skill
4. General clarity and voice editing

Do not force creative prose rules onto formal academic or exam answers, and do not use professional corporate language in school assignments unless requested.
