# Open Computer Use Skill

Platform-neutral computer-use guidance for a local MCP server and CLI that gives agents eyes and hands on macOS, Windows, and Linux through accessibility APIs plus screenshots.

## Best for
- desktop app inspection
- accessibility-tree and screenshot state
- click, type, scroll, drag, and keyboard actions
- multi-window workflows
- local MCP integration
- cross-platform computer use
- whole-desktop screenshots and observation

## Reference
https://github.com/opensymph/open-computer-use

## Armory guidance
Inspect application/window state before targeting element indexes or coordinates. Prefer semantic element actions and direct value setting. Re-observe after UI changes. Keep global input and externally visible actions explicitly gated, and avoid sensitive apps or unrelated private content.
