# Vercel Find Skills

## Purpose
Official Vercel skill-discovery workflow for finding and installing Agent Skills from the open ecosystem.

## What it does
- Uses `npx skills find [query]` to discover skills.
- Prioritizes popular, battle-tested skills and reputable sources.
- Helps identify skills for web development, testing, deployment, design, code quality, documentation, and productivity.
- Uses `npx skills add <owner/repo> --skill <name>` to install a selected skill.

## Useful commands
```bash
npx skills find <query>
npx skills add <owner/repo> --skill <skill-name>
npx skills list
npx skills check
npx skills update
```
