# Frontend Design Skill

Use for distinctive, polished frontend work instead of generic AI-generated templates.

## Focus
- deliberate visual hierarchy and typography
- strong composition and spacing
- coherent visual language
- purposeful motion and interaction
- responsive layouts
- accessibility and performance
- avoid repetitive card/gradient/glassmorphism patterns
