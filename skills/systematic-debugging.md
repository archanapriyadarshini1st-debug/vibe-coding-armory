# Systematic Debugging

A disciplined debugging workflow for agent-assisted development.

## Focus
- reproduce before changing code
- isolate the failing layer
- form testable hypotheses
- inspect logs, errors, state, and relevant code paths
- make the smallest evidence-based fix
- verify the fix and check for regressions

## Principle
Do not guess-and-patch. Build a minimal reproduction, identify the root cause, then validate the correction.
