# Video Use / AI Agent Video Editor

Conversation-driven video editing workflow covering transcription, edit planning, cutting, grading, overlays, subtitles, rendering, verification, and iteration.

## Best for
- talking heads, tutorials, interviews, montages, travel and general footage
- transcript-first editing
- FFmpeg-based production workflows
- animation slots using HyperFrames/Remotion/Manim
- render verification before delivery
